# MS-CISBA-Coursework-Portfolio

This repository brings together representative work from the eight core courses used in my capstone skills assessment. The work is organized into four areas: Data Analytics, Data Mining and Management, Systems Development, and Networking and Cybersecurity.

Some projects demonstrate skills I feel comfortable using independently, while others show areas where I am still developing. Two of the courses, CIDM 6355 and CIDM 5380, are currently in progress, so their folders will be updated as I complete new coursework.
